# Real Estate Aggregator Platform

This project is a multi-source real estate aggregator platform. It scrapes property listings from various websites, processes and normalizes the data, and provides a unified search interface for users.

## Project Structure

- **/scrapers**: Contains scraper workers for different real estate websites.
- **/data_processing**: Houses the service responsible for consuming raw scraped data, normalizing it, and storing it.
- **/backend**: Contains the backend API service to serve property data.
- **/frontend**: Contains the frontend single-page application for user interaction.
